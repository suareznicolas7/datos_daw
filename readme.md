# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- Sistema: Sistema de recomendación de contenido en Netflix.
- Contexto: Netflix es una plataforma de streaming que ofrece a sus usuarios una amplia gama de contenido audiovisual, como películas, series y documentales. Utiliza grandes volúmenes de datos generados por la interacción de los usuarios para personalizar las recomendaciones de contenido, mejorando la experiencia del usuario y aumentando la retención.

## 2) Conceptos
- Big Data: En el caso de Netflix, se generan y procesan enormes volúmenes de datos sobre las preferencias de visualización de los usuarios, sus hábitos de búsqueda, interacciones con la plataforma (como likes, comentarios, pausas, avances, etc.) y datos externos como ratings y tendencias sociales.
Análisis de datos: Netflix analiza estos datos para identificar patrones de comportamiento de los usuarios. Esto incluye la segmentación de usuarios, la clasificación de contenido basado en sus preferencias y la identificación de tendencias populares.

- Machine Learning (Aprendizaje Automático): Netflix utiliza algoritmos de aprendizaje automático para hacer predicciones sobre qué películas o series es más probable que le gusten a un usuario, basándose en su historial de visualización y en patrones similares de otros usuarios.
- 
- Deep Learning (Aprendizaje Profundo): Netflix emplea redes neuronales profundas para realizar recomendaciones aún más precisas y personalizadas. Estos modelos son capaces de aprender patrones complejos en grandes volúmenes de datos, como el análisis de las emociones en las reseñas o el contenido de los trailers de películas.
- 
- IA (Inteligencia Artificial): El sistema de recomendación de Netflix es un ejemplo de cómo la IA puede utilizar datos masivos para proporcionar decisiones personalizadas, como la sugerencia de qué ver a continuación, basándose en las preferencias y comportamientos previos del usuario.

## 3) Relación
- El sistema de Netflix usa grandes volúmenes de datos (Big Data) para entrenar modelos de Machine Learning que permiten a la IA recomendar contenido personalizado. Analizando los datos, detecta patrones de comportamiento y, con Deep Learning, mejora continuamente las recomendaciones adaptándose a cada usuario.

# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- Sistema: Sistema de recomendación de productos en Amazon.
- Contexto: Amazon es una de las plataformas de comercio electrónico más grandes del mundo, que utiliza grandes volúmenes de datos generados por la interacción de los usuarios con la página para personalizar las recomendaciones de productos. Este sistema mejora la experiencia de compra del usuario, aumenta las probabilidades de compra y optimiza las ventas de la empresa.

## 2) Conceptos
- Big Data: Amazon maneja grandes cantidades de datos generados por los usuarios, como sus búsquedas, compras previas, clics en productos, reseñas, y comportamientos de navegación. Estos datos se procesan para ofrecer recomendaciones de productos adaptadas a cada usuario.
  
- Análisis de datos: Amazon analiza los datos para identificar patrones en las preferencias de los usuarios, como productos que suelen comprar juntos, qué productos son más populares en determinadas épocas o qué artículos suelen interesar más a los compradores en función de su historial de navegación.

- Machine Learning (Aprendizaje Automático): Amazon utiliza algoritmos de aprendizaje automático para hacer predicciones sobre qué productos le gustarán a cada usuario, basándose en sus compras previas y en los comportamientos de otros usuarios con intereses similares.
  
Deep Learning (Aprendizaje Profundo): Amazon también emplea técnicas avanzadas de Deep Learning para refinar las recomendaciones, como analizar las descripciones de productos, reseñas de usuarios y patrones de compra más complejos para hacer recomendaciones más precisas y personalizadas.

- IA (Inteligencia Artificial): La IA es utilizada para personalizar la experiencia de compra, automatizando las recomendaciones de productos en función de los intereses, el historial de compra y las interacciones pasadas de cada usuario.

## 3) Relación
- Amazon usa Big Data para recolectar y analizar grandes volúmenes de datos sobre el comportamiento de los usuarios en su plataforma. Esto alimenta algoritmos de Machine Learning que permiten hacer predicciones sobre productos de interés para cada usuario. Con el uso de Deep Learning, el sistema mejora la precisión de las recomendaciones, ajustándolas constantemente a las preferencias individuales, lo que optimiza la experiencia de compra.

## 4) Pipeline
- Amazon recoge una variedad de datos de los usuarios para personalizar las recomendaciones de productos. Estos incluyen:
  + Historial de compras: Qué productos ha comprado un usuario anteriormente.
  + Búsquedas de productos: Qué productos ha buscado el usuario en la plataforma.
  + Interacciones con productos: Datos sobre los productos que el usuario ha visto, añadido al carrito, o marcado como favoritos.
  + Valoraciones y reseñas: Opiniones de los usuarios sobre productos específicos.
  + Comportamiento de navegación: El tiempo que el usuario pasa viendo un producto, las páginas que visita y los clics realizados.
  + Datos demográficos: Información como ubicación geográfica, dispositivo utilizado, y a veces el historial de compra asociado a tendencias regionales.
  + Preferencias de categorías: Qué tipo de productos o categorías (electrónica, ropa, libros, etc.) interesan más al usuario.

## 5) 5V del Big Data
- Volumen: Amazon maneja petabytes de datos sobre las interacciones de millones de usuarios de todo el mundo cada día.
  
- Velocidad: Los datos deben ser procesados y analizados en tiempo real para ofrecer recomendaciones instantáneas mientras el usuario navega por la página.
  
- Variedad: Los datos provienen de diversas fuentes, incluyendo el historial de compras, búsquedas, clics, reseñas de productos, e incluso las interacciones en dispositivos móviles.
  
- Veracidad: Los datos deben ser precisos y de alta calidad, lo que implica asegurar que las valoraciones de productos y la información de los usuarios sean fiables y representativas.
  
- Valor: El valor de estos datos radica en la capacidad de ofrecer recomendaciones de productos personalizadas que incrementan las ventas y mejoran la experiencia del cliente, generando mayor lealtad y retención.

## 6) Ejemplo aplicado
- Datos: Información sobre las compras previas, búsquedas realizadas, clics en productos, valoraciones de otros usuarios y datos de navegación en la plataforma.
  
- Análisis: Identificación de productos que los usuarios similares han comprado, análisis de la relación entre productos (por ejemplo, "usuarios que compraron X, también compraron Y") y tendencias de compra en tiempo real.
  
- Modelo: Se usan modelos de filtrado colaborativo para recomendar productos basados en comportamientos de usuarios similares y modelos basados en contenido para sugerir productos con características similares a los comprados previamente.
  
- Decisión: Amazon muestra productos recomendados en la página de inicio y en las páginas de productos, basados en el historial de navegación y compras del usuario, con el fin de aumentar las probabilidades de conversión.
